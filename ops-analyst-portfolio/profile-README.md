## How I work

1. **Define the metric before the dashboard** — an ops KPI nobody can act on is decoration.
2. **SQL first** — pull the raw truth from the source system, not a hand-maintained sheet.
3. **Automate the second time** — do a task manually once, script it the second time.
4. **Ship a one-page summary** — stakeholders read one page, not a 40-slide deck.
